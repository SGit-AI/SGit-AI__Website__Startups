# The honest column row on nfrs.sgit.ai

**What.** The repository guidance asks every repository to add one row to the honest column on nfrs.sgit.ai: which of the requirements that are not features it meets, measured, and which it does not. For this site: version control (yes), testing and CI (the gate and the finder test, yes), resilience (static, yes), backups (the repository only; no vault), explainability (the reality file), budgets (none written).

**Done when.** The row is on nfrs.sgit.ai, by a brief to that site's team, and the reality file links to it.

**From.** [Every sgit repository, section 8 and the checklist](https://sgit.ai/docs/guidance/repositories.html).
